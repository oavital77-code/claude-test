# Covered Call System

מערכת לניהול תיק מניות ואסטרטגיית covered call. כלי החלטה בלבד.

**האפיון המלא: docs/SPEC.md — קרא אותו לפני כל משימה חדשה.**

## חוקים לא-ניתנים-לעקיפה
- אין שליחת פקודות ל-IBKR. קריאה בלבד.
- כל סף מספרי ב-config.yaml. אין ערכים קשיחים בקוד.
- אין הזנה ידנית של מצב פוזיציה. פוזיציות נגזרות מטבלת trades בלבד.
- אין הצעת strike מתחת ל-avg_cost_adjusted.
- כל הנחה בענייני מס נרשמת ב-ASSUMPTIONS.md.

## עבודה
- בנה שלב אחד בכל פעם לפי סעיף 12 באפיון. אל תקפוץ קדימה.
- כתוב בדיקות ללוגיקה פיננסית: בסיס עלות, FIFO, roll, מס.
- לפני קוד חדש — הצג תוכנית וחכה לאישור.

## סטאק
Python 3.11, SQLite, FastAPI + Jinja2, ib_async, pandas
