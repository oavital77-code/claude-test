# Covered Call System

כלי עזר אישי לאיתור מניות והפעלת אסטרטגיית covered call. **אינו** שולח פקודות לברוקר, **אינו** ייעוץ השקעות, **אינו** חוות דעת מס.

האפיון המלא: [`docs/SPEC.md`](docs/SPEC.md). כללי עבודה: [`CLAUDE.md`](CLAUDE.md).

## התקנה

```bash
cd covered-call-system
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## הרצה (שלבים 1–4 — היומן + מחירים חיים + שכבת האופציות + המסנן)

```bash
python -m src.db.init_db      # יוצר את data/portfolio.db מהסכמה
uvicorn src.web.app:app --reload
```

לאחר מכן פתח דפדפן בכתובת שמודפסת בפלט (בד"כ http://127.0.0.1:8000).

מחירי מניות (שלב 2), מחירי אופציות וחיפוש חלופות roll (שלב 3) דורשים
**TWS או IB Gateway רצים ברקע** עם ה-API מופעל, ופרטי החיבור תואמים
ל-`config.yaml` (`ibkr.host` / `ibkr.port`). הכפתורים המתאימים בעמודי
הפוזיציות/האופציות מבצעים שליפה חד-פעמית (אין ריצה אוטומטית/cron). ללא
TWS/Gateway רץ, הם יציגו הודעת שגיאה ברורה בעברית במקום לקרוס — זו
התנהגות צפויה, לא תקלה. כברירת מחדל המערכת מבקשת נתונים מושהים (~15 דק')
כדי לא לדרוש מנוי OPRA; לשנות ל-`prefer_live_market_data: true`
ב-config.yaml אם יש מנוי מתאים.

עמוד **האופציות** (`/options`) מציג את פוזיציות האופציה הפתוחות, ימים
לפקיעה, % פרמיה שנתפס, והתראות ניהול (סעיף 8 באפיון: סגירת רווח, roll,
אקס-דיבידנד, חציית strike). עמוד **התראות** (`/alerts`) מרכז את
ההתראות הפעילות עם אפשרות "התעלם" — ר' ASSUMPTIONS.md #16 לגבי
הסמנטיקה המדויקת של דחיית התראה.

עמוד **הסורק** (`/screener`) מריץ את המסנן (סעיף 6): פונדמנטלי (איכות +
ערך) מ-**Yahoo Finance** (`yfinance` — ספק שנבחר ללא אישור מפורש כי
השאלה שנשאלה לא נענתה; ר' ASSUMPTIONS.md #20) ונזילות אופציות מ-IBKR.
אין מקור ל"סריקת כל השוק" — יש להזין טיקרים ידנית (שורה לכל טיקר,
ברירת מחדל NASDAQ/USD, או `TICKER:EXCHANGE:CURRENCY` לדריסה). הפלט:
טבלה מדורגת עם ציון משוקלל והצעת strike/expiry קונקרטית לתרחישי
CORE ו-INCOME לכל טיקר.

## שלבי הבנייה

ראה סעיף 12 ב-`docs/SPEC.md`. נכון לעכשיו: **שלבים 1–4** (היומן, חיבור
IBKR לקריאה בלבד, שכבת האופציות, והמסנן) מומשו. המס עדיין לא ממומש.

## נקודות מס שדורשות אימות מול רו"ח

הלוגיקה הבאה (מודול המס, שלב 5) **טרם מומשה**, אך יש לאמת עם רו"ח לפני קיבוע:

1. בניירות זרים החישוב בשקלים — רווח משער החליפין נכלל בבסיס המס. יש לוודא יישום מדויק.
2. טיפול ב-roll: סגירה בהפסד ופתיחה חדשה הם שני אירועים נפרדים באותו יום.
3. כללי קיזוז הפסדים בין אופציות, מניות ודיבידנדים.
4. מיסוי דיבידנדים, ניכוי במקור אמריקאי (W-8BEN) והזיכוי בישראל.

ראה גם [`ASSUMPTIONS.md`](ASSUMPTIONS.md) להנחות נוספות שהתקבלו במהלך הפיתוח.
